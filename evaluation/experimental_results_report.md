## III. MATHEMATICAL CONSISTENCY VERIFICATION

Each metric reported in Table 1 strictly satisfies the standardized mathematical definitions derived directly from the counts of TP, TN, FP, and FN.

$$\text{Accuracy} = \frac{\text{TP} + \text{TN}}{\text{TP} + \text{TN} + \text{FP} + \text{FN}}$$

$$\text{Precision} = \frac{\text{TP}}{\text{TP} + \text{FP}}$$

$$\text{Recall} = \frac{\text{TP}}{\text{TP} + \text{FN}}$$

$$\text{F1-Score} = \frac{2 \times \text{Precision} \times \text{Recall}}{\text{Precision} + \text{Recall}} = \frac{2 \times \text{TP}}{2 \times \text{TP} + \text{FP} + \text{FN}}$$

### Verification Proofs for Sample Binary Models:

1. **Breast Cancer**:
   - $\text{Accuracy} = \frac{39 + 72}{114} = \frac{111}{114} = 97.368\% \rightarrow \mathbf{97.37\%}$
   - $\text{Precision} = \frac{39}{39 + 0} = 100.0\% \rightarrow \mathbf{100.00\%}$
   - $\text{Recall} = \frac{39}{39 + 3} = \frac{39}{42} = 92.857\% \rightarrow \mathbf{92.86\%}$
   - $\text{F1-Score} = \frac{2 \times 39}{2(39) + 0 + 3} = \frac{78}{81} = 96.296\% \rightarrow \mathbf{96.30\%}$

2. **Stroke**:
   - $\text{Accuracy} = \frac{41 + 714}{1022} = \frac{755}{1022} = 73.874\% \rightarrow \mathbf{73.87\%}$
   - $\text{Precision} = \frac{41}{41 + 258} = \frac{41}{299} = 13.712\% \rightarrow \mathbf{13.71\%}$
   - $\text{Recall} = \frac{41}{41 + 9} = \frac{41}{50} = 82.000\% \rightarrow \mathbf{82.00\%}$
   - $\text{F1-Score} = \frac{2 \times 41}{2(41) + 258 + 9} = \frac{82}{349} = 23.495\% \rightarrow \mathbf{23.50\%}$

3. **Hepatitis**:
   - $\text{Accuracy} = \frac{20 + 5}{31} = \frac{25}{31} = 80.645\% \rightarrow \mathbf{80.65\%}$
   - $\text{Precision} = \frac{20}{20 + 1} = \frac{20}{21} = 95.238\% \rightarrow \mathbf{95.24\%}$
   - $\text{Recall} = \frac{20}{20 + 5} = \frac{20}{25} = 80.000\% \rightarrow \mathbf{80.00\%}$

## V. CLINICAL PERFORMANCE ANALYSIS & SYSTEM DESIGN PATTERNS

### 1. Severe Imbalance Handling & High Sensitivity Bias
- **Stroke Model**: Features extreme positive class imbalance (~4.9% positive stroke prevalence in data). The model was trained with `scale_pos_weight = 19.54` to prioritize **clinical sensitivity**. Consequently, it achieved an 82.00% Recall (missing only 9 true stroke cases out of 50), while accepting 258 False Positives, resulting in a low Precision of 13.71%. In acute stroke triage, missing a stroke (FN) is life-threatening, making high recall a clinical necessity over high precision.

### 2. High-Precision Zero False Positive Models
- **Breast Cancer, Diabetes, Lung Cancer, Kidney**: These models achieved **100.00% Precision** on the test set ($\text{FP} = 0$). For screening workflows, this guarantees that when the system issues a positive alert for these diseases, clinicians can trust the output with near-zero false alarm rate.

### 3. Impact of Feature Signal Strength
- **Chronic Kidney Disease (100% across all metrics)**: Key biomarkers like serum creatinine (`Sc`), hemoglobin (`Hemo`), and specific gravity (`Sg`) provide clean, linearly separable boundaries for renal failure prediction.
- **Chronic Liver Disease (63.25% Accuracy)**: Bilirubin and liver enzyme ratios exhibit substantial physiological overlap between early-stage hepatic dysfunction and healthy non-liver controls, reflecting the biological complexity of hepatic diagnostics.
